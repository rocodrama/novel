# 새 작품 세팅

공통 규칙은 노션 NOVEL › 공통세팅 페이지가 기준이다. 이 스킬은 그 규칙대로 작품 하나의 작업 공간을 만든다.

## 0. 입력 모으기

없으면 사용자에게 묻는다. 기획이 이미 대화에 있으면 거기서 가져온다.

| 항목 | 예 |
|---|---|
| 플랫폼 | `novelpia` 또는 `munpia` |
| 작품 제목 | 내가 보는 하꼬 버튜버가 초절정 미녀 전학생이었다 |
| 폴더 이름(짧게) | 하꼬 버튜버 전학생 |
| 장르(한국어) | 연예계+로맨스 / 로판+빙의 / 현판+회귀 … |
| 목표 화수 | 120 (회차당 공백 포함 5,000자 이상) |
| 로그라인, 재미 포인트, 제목 후보 | 기획에서 |
| 주인공·여주 기본값 | 이름, 욕망, 결함 (init 인자로 씀) |

## 1. 제목 중복 확인 (먼저)

이미 있는 작품과 겹치면 기획 전체가 무너진다. 세팅보다 먼저 확인한다.

- 웹 검색: `"<제목 핵심 구절>" 웹소설`, `<핵심 조합 키워드> 웹소설` (예: "악역 영애 집사")
- 같은 제목은 물론 **같은 핵심 조합(인물 관계·설정)의 기존 작품**이 있는지 본다.
- 플랫폼 내부 작품은 외부 검색에 잘 잡히지 않으니, 못 찾았으면 "연재 전에 플랫폼에서 직접 검색 필요"를 연재 준비 체크리스트에 남긴다.
- 겹치면 멈추고 사용자에게 차별화 방향을 제안한다.

## 2. 노션 작품 페이지

1. 노션에서 `NOVEL` 페이지를 찾아 읽는다(검색어 "NOVEL"). 플랫폼 섹션 제목은 `## 노벨피아`, `## 문피아`다.
2. NOVEL 페이지를 부모로 작품 페이지를 만든다. 아이콘은 작품 분위기에 맞는 이모지 하나. 본문은 `references/notion-templates.md`의 "작품 페이지"를 쓰되, 하위 페이지와 회차 표는 아직 넣지 않는다.
3. 작품 페이지를 부모로 하위 페이지 8개를 만든다(같은 문서의 템플릿): 진행 단계 ✅, 1. 기획 💡, 2. 설정 📚, 3. 비주얼 🎨, 4. 플롯 🗺️, 5·6. 집필·퇴고 ✍️, 7. 연재 준비 📕, 8. 반응 기록 📈
4. 작품 페이지를 부모로 데이터베이스 "회차 관리"를 만든다(같은 문서의 스키마). 부 옵션은 작품의 부 구성에 맞춘다.
5. 작품 페이지 본문을 다시 쓴다: 콜아웃 → 하위 페이지 8개 → 구분선 → 회차 관리(inline). 페이지 블록은 **이미 있는 `<page url>` 태그를 옮기는 방식**으로만 배치할 수 있다(새 URL 태그를 추가하면 거부됨).
6. NOVEL 페이지에서 새 작품 페이지 태그를 맨 끝에서 지우고 해당 플랫폼 섹션 아래로 옮긴다(한 번의 update에 두 개의 content_updates).
7. 노션 저장 형태(`<b>`, `\~`, `<br />`) 때문에 문자열 매칭이 실패하면 페이지를 다시 읽고 저장된 형태로 고친다.

## 3. 작품 폴더 초기화 (webnovel-writer-ko)

```bash
S=$(ls -d ~/.claude/plugins/cache/webnovel-writer-ko/webnovel-writer/*/scripts | sort -V | tail -1)
python -X utf8 $S/webnovel.py init "D:/novel/<플랫폼>/<폴더 이름>" "<작품 제목>" "<장르>" \
  --protagonist-name "<주인공>" --target-words <화수×5000> --target-chapters <화수> \
  --protagonist-desire "<욕망>" --protagonist-flaw "<결함>" \
  --heroine-config "<단여주 등>" --heroine-names "<여주>" \
  --world-scale "<배경>" --power-system-type "<능력 체계 또는 '초능력 없음'>" \
  --target-reader "<독자층>" --platform "<노벨피아/문피아>"
```

- 출력의 `genre_tags`(`.webnovel/state.json`)가 비어 있지 않은지 확인한다. 비어 있으면 장르명을 한국 장르 별칭(로판, 현판, 헌터물, 겜판, 무협, 대체역사, 아카데미, 아포칼립스, 스포츠, 연예계, 전문직, 판타지, 로맨스)으로 바꿔 다시 한다.
- 설정집 본문 채우기, 전체 개요, 회차 플롯은 이 스킬의 범위가 아니다. 이어서 `/webnovel-init` 문답이나 `/webnovel-plan`으로 진행한다.

## 4. 구글 드라이브 폴더

`G:\내 드라이브\novel\<플랫폼>\<폴더 이름>` 아래에 `원고`, `이미지`, `표지`, `연재` 폴더를 만든다. 드라이브 경로에 접근 권한이 없으면 먼저 권한을 요청한다.

작품 폴더 자체는 드라이브에 두지 않는다(작품 폴더의 SQLite가 동기화와 충돌할 수 있음).

## 5. 작품 CLAUDE.md

작품 폴더에 `CLAUDE.md`를 만든다. `references/notion-templates.md` 끝의 "CLAUDE.md 템플릿"을 채운다. 이 파일 덕분에 작품 폴더에서 새 세션을 열면 규칙을 바로 읽는다.

## 6. 보고

만든 것(노션 페이지, 작품 폴더, 드라이브 폴더, CLAUDE.md)과 제목 중복 확인 결과를 알리고, 다음 단계(설정 → 캐릭터 디자인 스킬 → 플롯)를 안내한다.
