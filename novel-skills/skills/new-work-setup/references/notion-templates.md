# 노션 템플릿

`{중괄호}`는 채워 넣는다. 노션 마크다운 규칙: 콜아웃은 `<callout icon="" color="">`, 줄바꿈은 줄 끝 `\`.

## 작품 페이지 (콜아웃)

```
<callout icon="📌" color="{pink_bg|blue_bg|purple_bg}">
**플랫폼** {노벨피아} · **장르** {장르} · **목표** {N}화 완결 후 연재\
**현재 단계** 1. 기획 · **작품 폴더** `D:\novel\{플랫폼}\{폴더 이름}` · **드라이브** `G:\내 드라이브\novel\{플랫폼}\{폴더 이름}`
</callout>
```

## 하위 페이지

### 진행 단계 (✅)
```
- [x] 0. 세팅: 노션 작품 페이지
- [ ] 0. 세팅: 작품 폴더, 드라이브 폴더(원고·이미지·표지·연재), 피그마 파일
- [ ] 1. 기획: 제목 중복 확인, 로그라인·차별점·제목 확정
- [ ] 2. 설정: `/webnovel-init`, 주요 인물 5명 확정, Codex 교차 검토
- [ ] 3. 비주얼: 캐릭터 디자인(character-design 스킬), 관계도
- [ ] 4. 플롯: 전체 개요, 부 구성, 1부 회차 플롯(`/webnovel-plan`)
- [ ] 5. 집필: 1~30화 (회차마다 episode-finish 스킬)
- [ ] ★ 30화 중간 점검: 1~3화 피드백
- [ ] 5. 집필: 31화~완결
- [ ] 6. 퇴고: 전체 문체, 설정 오류 검사
- [ ] 7. 연재 준비: 표지, 소개글, 태그, 업로드 일정, AI 규정 확인
- [ ] 8. 연재·분석
```

## CLAUDE.md 템플릿

```markdown
# {작품 제목}

- 플랫폼: {노벨피아} / 장르: {장르} / 목표: {N}화 완결 후 연재
- 이 폴더는 webnovel-writer-ko 작품 프로젝트입니다. 설정·떡밥·상태의 원본은 이 폴더(`设定集/`, `大纲/`, `.webnovel/`)입니다.
- 노션 작품 페이지: NOVEL › {노벨피아} › 이 작품 (진행 관리, 회차 관리 표, 반응 기록)
- 드라이브 백업: `G:\내 드라이브\novel\{플랫폼}\{폴더 이름}` (원고·이미지·표지·연재)

## 작업 규칙
- 출력과 원고는 모두 한국어. 회차는 공백 포함 5,000자 이상(권장 5,000~6,000자), 끝은 반드시 절단.
- 시점: {시점}. 채팅·메시지 표기: {표기 규칙}.
- 절대 규칙: {규칙}. 실존 브랜드·플랫폼·인물 이름 금지.
- 회차를 쓰면 episode-finish 스킬로 마감한다(점검, Codex 검수, 커밋, 드라이브 백업, 노션 갱신).
- 부가 끝날 때마다 Codex로 설정 오류를 교차 검토한다.
```
